# Prior-art boundaries

The Council kernel composes established system ideas under A11oy-specific authority contracts. The sources below are references, not claims of authorship.

- Temporal durable execution and event-history recovery: <https://docs.temporal.io/temporal>
- Open Policy Agent policy-as-code and external decision points: <https://www.openpolicyagent.org/docs/latest/>
- Model Context Protocol authorization boundary: <https://modelcontextprotocol.io/specification/2025-06-18/basic/authorization>
- Agent2Agent protocol interoperability: <https://a2a-protocol.org/latest/specification/>
- DSSE envelope protocol: <https://github.com/secure-systems-lab/dsse/blob/master/protocol.md>
- in-toto supply-chain attestations: <https://in-toto.io/>
- Mixture-of-Agents: <https://arxiv.org/abs/2406.04692>

A11oy-specific composition in this package includes categorical role vetoes, exact-target capability admission, eight-axis adviser-correlation discounting, retained minority reports, explicit action-state compilation, and honest separation between hash-chain integrity and signature state.

No external implementation is copied into this package. The source uses only the Python standard library.
