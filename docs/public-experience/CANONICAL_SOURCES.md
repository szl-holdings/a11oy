# A11oy public experience canonical sources

This note records the source and deployment path for public-experience v1. It
does not treat a source file, successful build, or reachable URL as proof of a
current deployment.

## Source map

| Responsibility | Canonical source | Runtime/output relationship |
|---|---|---|
| Product document and semantic fallback | `a11oy_landing.html` | Served as `/` by `serve.py`; copied explicitly into the image. |
| Experience controller | `console/assets/a11oy-public-experience-v1.js` | Served from `/assets/a11oy-public-experience-v1.js`; consumes only the versioned experience API. |
| Experience visual contract | `console/assets/a11oy-public-experience-v1.css` | Served from `/assets/a11oy-public-experience-v1.css`; dark, gold, and teal house palette. |
| Lazy holographic renderer | `static/a11oy_landing.js` | Served from `/static/a11oy_landing.js`; progressive enhancement over the semantic graph. |
| Typed API and state machine | `a11oy_public_experience.py` | Registered into the existing FastAPI app by `serve.py`; there is no second server. |
| Public scenario allowlist | `config/public-experience/scenarios.v1.json` | Read at service registration; malformed or noncanonical state fails closed. |
| Public presentation projection | `config/public-experience/estate-projection.v1.json` | Must exactly cover the public IDs in the canonical estate manifest. |
| Public estate authority | `governance/public-estate.v1.json` | The source of public product IDs, public URLs, source repositories, and allowed hosts. |
| Runtime entry point | `serve.py` and `Dockerfile` | Routes register before the SPA catch-all; every route-serving file and config is explicitly copied. |
| Canonical Space deployment | `.github/workflows/hf-sync.yml` | A protected `main` push invokes the pinned reusable single-writer deployment, source-binds the Space, probes the runtime, then relocks it. |
| Flagship publisher | `scripts/hf_publish_vertical_flagships_v4.py` and `scripts/hf_publish_vertical_flagships_v4_impl.py` | Existing post-deploy publisher. Public-experience v1 does not silently claim a flagship changed unless its generated bytes and live runtime are separately proven. |
| Release gate | `scripts/verify_public_experience.py` | Static/build, read-only HTTP, and explicitly enabled bounded-simulation verification; emits a machine-readable report. |

The new controller, CSS, renderer, registry projection, and API are source files,
not generated artifacts. Deployment artifacts are derived from the Dockerfile
copy closure by the reusable Hugging Face deployment workflow.

## Public origin roles

- `https://a-11-oy.com` is the named product origin. Repository records show it
  has been served independently of the automatic Space deploy, including a
  static/edge or operator-rebuilt origin. It must be probed separately after a
  release; a healthy Space does not prove this apex is current.
- `https://szlholdings-a11oy.hf.space` is the canonical automatically deployed
  application runtime for this repository. Its `/api/build-info` revision is
  the authoritative runtime/source binding checked by `hf-sync.yml`.
- `https://a11oy.net` is the separate proof and conformance registry. It is not
  the product application host and is not changed by this front-door build.
- GitHub Pages hosts static project/status material in this estate. A Pages 200
  is not proof that the FastAPI experience routes or the canonical Space image
  are deployed.

These roles are intentionally distinct. Every release report must name which
origin was tested, the observed revision when available, and whether the test
was static, API, deployment, or runtime evidence.
